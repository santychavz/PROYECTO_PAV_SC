# Simulador Virtual de la Simpletron

## Descripción

Este repositorio fue creado para desarrollar el proyecto **Simulador Virtual de la Simpletron** en lenguaje C.

El objetivo general del proyecto será implementar un simulador capaz de cargar y ejecutar programas escritos en SML (Simpletron Machine Language), utilizando una memoria de 100 posiciones y las operaciones definidas para la computadora Simpletron.

## Primera entrega

En esta primera entrega se realiza únicamente la **definición e inicialización del repositorio de GitHub**, de acuerdo con las indicaciones del proyecto.

El repositorio servirá como espacio de trabajo para registrar mediante commits los diferentes avances realizados durante el desarrollo del simulador.

## Estado del proyecto

**Etapa actual:** Primera entrega — creación y definición del repositorio.

La implementación del simulador se realizará en entregas posteriores conforme se indiquen los avances del proyecto.
